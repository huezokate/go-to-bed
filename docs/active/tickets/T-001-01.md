## Context

Before Claude stops and shows the speech bubble, he should play a short wave animation — arm raised, a couple frames of waving. Makes the interaction feel less abrupt and more characterful.

## Acceptance Criteria

- [ ] At least 2 wave frames added to `FRAMES` (arm raised variants of the existing pixel art)
- [ ] Wave sequence plays once when Claude reaches the center pause zone, before `bubble_visible` is set to `True`
- [ ] Wave frames cycle at the same 120ms tick rate as walk frames
- [ ] After the wave sequence completes, behavior continues as before (pause + show bubble)
- [ ] No visual glitches or frame bleed between walk → wave → pause transitions
