## Context

When Claude appears with his bedtime message, clicking the sprite or bubble should snooze him — dismiss the current window and relaunch the script 15 minutes later, so he comes back if you're still up.

## Acceptance Criteria

- [ ] Clicking anywhere on the canvas while the bubble is visible triggers snooze
- [ ] On snooze: window fades out (same fade as normal exit)
- [ ] After fade, a background process is scheduled to relaunch `bedtime_claude.py` in 15 minutes (using `subprocess` + `sleep 900`)
- [ ] Snooze message replaces the bubble text briefly before fade: *"Fine. 15 more minutes. 😑"*
- [ ] Clicking outside the pause/bubble phase (while Claude is walking) does nothing
- [ ] No zombie processes left behind if the user closes the window through other means
